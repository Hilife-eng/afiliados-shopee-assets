Política de Privacidade

Última atualização: 2024

Este aplicativo ("Afiliados Shopee Bot") é uma ferramenta de automação interna para publicação de ofertas de afiliados no Pinterest.

Dados coletados

  • Tokens de acesso OAuth (armazenados localmente, não compartilhados)
  • IDs de pins criados (para gerenciamento)

Uso dos dados

Os dados são usados exclusivamente para:

  • Autenticar na API do Pinterest
  • Publicar pins de produtos afiliados

Compartilhamento

Nenhum dado é compartilhado com terceiros.
